# Architecture invariants

This page outranks every plan, design doc and project decision record in this repo, and a decision binds only when it has a row in [decisions.md](decisions.md).

This page, `decisions.md`, the tests and pins under `packages/at_client/test/architecture/`, `.github/wasm_gates.yaml`, the agent instruction files (`AGENTS.md`, `CLAUDE.md`, `.github/copilot-instructions.md`) and every test, gate, CI workflow and lint setting a row names as its check, with the fixtures and vectors those read, have code owners, listed in [CODEOWNERS](../../.github/CODEOWNERS). A change to any of them needs a code owner's approval. A pin move, which is a change to a guard's allow-list or golden, goes in a small PR of its own, ahead of the change that needs it.

Each row gives the rule, the mechanism to use instead, what a breach looks like in a diff, the check that holds it, and **Exceptions**: the number of places in the workspace packages that break the rule, made by the command listed under [How the counts were made](#how-the-counts-were-made). That number may only fall, and `test/architecture/counts_test.dart` fails when one rises. "Not counted" means nobody has counted. A rule with a check is held by the check; a rule without one is held by review. Rules in [docs/sdk-shape.md](../sdk-shape.md) are cited by number and not repeated here. An Id is permanent and never reused: a gap in the numbering is not free for a new rule.

## Keys

| Id | Rule | Use instead | A breach looks like | Check | Exceptions |
|---|---|---|---|---|---|
| K4 | Nothing puts a customer's keys at risk. Key files are written only through a `WrittenAtKeysIo`, and key material is added through `WrittenAtKeysIo.update`, never by a hand-rolled read, mutate and `flush`. A write goes elsewhere first, checks that everything already there survives, then swaps. A migration copies and keeps the old form until a later major. Concurrent writers use an atomic or conditional update; the server-held `@keys` store, whose atServer offers neither, holds the enrollment's lock, a `ServerMutex` record, from before it reads the document until it puts. That lock is not a fence: a put sent while the lease is held can land after it expires, once another writer has taken the lock and put, and then drops that writer's material while both read-backs match; the only guard is that a put needs at least half the lock's ttl left on its lease. Tests never touch the real key directory. | `WrittenAtKeysIo.update`, as `FileAtKeysIo` and `KeychainAtKeysIo` implement it. | Two unawaited tasks that each read the keys, add one and `flush`; a migration that deletes the old entries in the release that copies them. | None yet. | 1: `InMemoryAtKeysIo`, documented as for tests, keeps the default `update` |
| K5 | An exception message or a log line carries types, names and positions, never key material or a secret. Key material sealed or encrypted, such as a sealed `@keys` document's `iv` and `ct`, counts as key material. Other text read from the wire appears in one only quoted, with its control and format characters escaped and its length clipped, as `quotedClaim` does. | The exception's type, the offset, the field's name; for other text read from the wire, a helper that quotes, escapes and clips it, as `quotedClaim` does. | A `FormatException` caught while decoding a private key and put into a message, which quotes the key's text; a reply put into a message raw or without quotes. | None yet. | Not counted |
| K6 | A miss on key material fetches or asks only for what the Atsign itself advertised, never for an id a peer chose. | A superseded generation listed as retired in the Atsign's advertisement. | A lookup for whatever key id a shared record names. | None yet. | Not counted |
| K7 | An AtKeys store holds at most one pending enrollment request, and an app can always continue with it, if only to cancel it. Its app and device names are labels the Atsign's owner sees; no code chooses a request by them. | `Atsign.enroll`, which refuses an AtKeys store holding a pending request or live keys, and checks again inside the store's update as it files; `Atsign.resumeEnrollment`, which returns the store's one request whatever its names; `PendingEnrollment.cancel`. | A second request filed beside or over a first; a resume that narrows by app or device and finds nothing in an AtKeys store that holds a request; a screen or command that waits on a pending request and offers no way to cancel it. | `test/lifecycle/enroll_test.dart` in `at_client`: "Two enrolls on one store at once file one request" and "The one pending enrollment resumes whatever app and device are given". | Not counted |

## How the counts were made

Each command runs from the repository root, over the tracked files, at the commit that last changed this page; its result is quoted beside it. `test/architecture/counts_test.dart` runs every command below under bash with `pipefail`, and fails when a result exceeds the number quoted, when a command fails or writes to stderr, and when a bullet here is not a count line; when a result falls, lower the number here. The workspace packages are the 13 library packages in the root `pubspec.yaml`'s `workspace:` block, and most commands search their `lib/` trees:

```sh
W="packages/at_auth/lib packages/at_chops/lib packages/at_cli_commons/lib packages/at_client/lib packages/at_client_cli/lib packages/at_client_flutter/lib packages/at_commons/lib packages/at_contact/lib packages/at_lookup/lib packages/at_onboarding_cli/lib packages/at_policy/lib packages/at_telemetry/lib packages/at_utils/lib"
```

- A1, upward imports, with `at_commons` lowest, then `at_utils`, then `at_chops` and `at_lookup` (equal, and neither may import the other), then `at_auth`, then `at_client`, then every other workspace package; imports among those others are not ranked: `git grep -nP "^\s*(import|export)\s+['\"]package:at_\w+" -- $W | awk -F"['\"]" -v R="at_commons=0 at_utils=1 at_chops=2 at_lookup=2 at_auth=3 at_client=4 at_cli_commons=5 at_client_cli=5 at_client_flutter=5 at_contact=5 at_onboarding_cli=5 at_policy=5 at_telemetry=5" 'BEGIN{n=split(R,x," ");for(i=1;i<=n;i++){split(x[i],kv,"=");r[kv[1]]=kv[2]}} {split($1,a,"/");split($2,b,"[:/]");s=a[2];t=b[2]; if(s!=t && (t in r) && (r[t]>r[s] || (r[t]==r[s] && r[s]<5))) print}' | wc -l` gives 0.
