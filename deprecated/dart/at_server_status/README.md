# at_server_status

`at_server_status` is retired and has been removed from this repository as a
maintained package.

Replacement: `checkAtSignServer(lookUp, atSign)` in at_lookup 4, from
`package:at_lookup/at_lookup.dart`. It reports whether an atSign is in the
atDirectory, whether its atServer answers, and whether the atSign has been
activated, with the cause of any failure, over the caller's own lookup.

Last published package:

https://pub.dev/packages/at_server_status

Its last release, 1.1.1, needs at_lookup 3, so it does not resolve beside
at_lookup 4.
