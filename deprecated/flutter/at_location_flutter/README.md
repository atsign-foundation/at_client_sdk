# at_location_flutter

`at_location_flutter` is deprecated and has been removed from this repository
as a maintained Flutter package.

Replacement: a location-sharing example in `at_client_flutter` is planned,
built on `AtCollection<T>` records rather than a standalone plugin package.

Last published package:

https://pub.dev/packages/at_location_flutter

The old package bundled location-sharing state, map UI, dialogs, helper
widgets and platform plugin scaffolding into a reusable Flutter package. The
replacement direction is app-owned code built directly on `at_client` and
`at_client_flutter`, without a separate plugin package, platform folders or
custom widget helpers.
