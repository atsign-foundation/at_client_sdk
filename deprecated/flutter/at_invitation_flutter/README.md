# at_invitation_flutter

`at_invitation_flutter` is deprecated and has been removed from this repository
as a maintained Flutter package.

Replacement: `AtClientInvitations` in `at_client`
(`package:at_client/at_client_mixins.dart`), shown in the Flutter app at
`packages/at_client_flutter/example/invitations`.

Last published package:

https://pub.dev/packages/at_invitation_flutter

Invitations now live in `at_client` itself, so a Flutter app and a CLI use
the same code, without a separate plugin package, platform folders or custom
widget helpers.
