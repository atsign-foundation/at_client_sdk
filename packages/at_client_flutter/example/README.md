# example

Minimal Flutter example for the at_client_flutter package. See
`lib/main.dart`.

Copy/paste snippets live in `lib/snippets`. Invitations, which replace the
deprecated `at_invitation_flutter` package, have their own app in
[`invitations`](invitations).

For a more complete reference app, see the todos example at
[`packages/at_client_flutter/example/todos`](todos).
