# at_client_wasm

Browser key custody for at_client.
This is a pre-release and unpublished package intended for WebAssembly/browser targets.

## Dev harness pages

- `web/index.html`: at_client JS dev session; enter an atSign, app and proxy host, then drive the client from the page log.
- `web/talk.html`: browser chat with the at_talk CLI (see [at-talk demo](../../docs/projects/wasm/at-talk-demo.md)).
